Resultado

El modelo MODNet está optimizado para retratos de personas — para otros motivos (animales, objetos, paisajes) el resultado puede ser impreciso. El modelo (~26 MB) se carga solo al abrir la herramienta. Todo se ejecuta en el navegador, la imagen no se envía a ningún sitio.

Dónde y cómo se procesa

Cuando inicias la herramienta, el contenido introducido se envía mediante el servidor VeVit a un modelo de IA externo.
