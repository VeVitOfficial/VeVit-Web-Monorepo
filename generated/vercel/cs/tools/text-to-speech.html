Text na řeč (TTS)

Lokálně Dostupný

Přečtěte text nahlas přes Web Speech API.

Nástroj je připraven.

Používá Web Speech API prohlížeče. Český hlas nemusí být dostupný — záleží na systému/OS. Nic se neodesílá na server (vyjma hlasů, jež dodává prohlížeč/OS).

Kde a jak probíhá zpracování

Soubor se zpracovává ve vašem prohlížeči a neopustí tento počítač.
