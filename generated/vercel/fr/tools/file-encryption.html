Chiffrement de fichiers

En local Disponible

Chiffre/déchiffre un fichier AES-256-GCM (Web Crypto).

Déposez le fichier à chiffrer Chiffré avec AES-256-GCM, clé dérivée du mot de passe (PBKDF2)

Sortie : .vevitenc (magic + salt[16B] + IV[12B] + ciphertext+tag). Sans le mot de passe le fichier est irrécupérable — conservez-le en sécurité. S'exécute localement via Web Crypto.
