L’outil est prêt.

Glissez une image (PNG) Stéganographie LSB — ne fonctionne que sur les formats sans perte (PNG)

LSB (Least Significant Bit) dans les canaux RGB. Fonctionne localement. Le PNG est réencodé via canvas — les métadonnées d'origine ne sont pas effacées, mais les données cachées persistent. JPEG ne peut pas être utilisé (la compression avec perte détruit le message).

Où et comment se fait le traitement

Le fichier est traité dans votre navigateur et ne quitte pas cet ordinateur.
