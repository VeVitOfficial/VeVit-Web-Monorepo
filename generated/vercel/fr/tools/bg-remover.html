L’outil est prêt.

Déposez une photo (idéalement un portrait) Suppression de fond par IA (ONNX MODNet, fonctionne localement)

Résultat

Le modèle MODNet est optimisé pour les portraits de personnes — pour d'autres sujets (animaux, objets, paysages) le résultat peut être imprécis. Le modèle (~26 Mo) se charge uniquement à l'ouverture de l'outil. Tout fonctionne dans le navigateur, l'image n'est jamais envoyée.

Où et comment se fait le traitement

Après votre action explicite, le contenu saisi est envoyé via le serveur VeVit à un modèle d’IA externe.
