Dateiverschlüsselung

Lokal Verfügbar

Ver-/entschlüsselt eine Datei mit AES-256-GCM (Web Crypto).

Datei zum Verschlüsseln ziehen Verschlüsselt mit AES-256-GCM, Schlüssel aus Passwort (PBKDF2)

Ausgabe: .vevitenc (magic + salt[16B] + IV[12B] + ciphertext+tag). Ohne Passwort ist die Datei nicht wiederherstellbar — sicher aufbewahren. Läuft lokal über Web Crypto.
