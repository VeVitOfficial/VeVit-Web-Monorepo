Результат

Модель MODNet оптимізована для портретів людей — для інших мотивів (тварини, предмети, пейзажі) результат може бути неточним. Модель (~26 МБ) завантажується лише при відкритті інструменту. Усе працює в браузері, зображення нікуди не надсилається.
