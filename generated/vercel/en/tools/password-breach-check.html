Password breach check

Locally Available

Checks whether a password has leaked (HIBP k-anonymity).

The tool is ready.

k-anonymity method (HIBP): a SHA-1 is computed from the password and only the first 5 characters of the hash are sent, not the password itself. The response is compared locally. Runs over HTTPS to api.pwnedpasswords.com.

Where and how processing happens

The file is processed in your browser and never leaves this computer.
