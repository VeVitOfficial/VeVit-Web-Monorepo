# Release 0, Task 0.1 — bezpečný bootstrap, konfigurace, session a HTTP

**Datum:** 29. 7. 2026
**Stav:** Implementováno a ověřeno v rozsahu uvedených testů

## Změna

- Konfigurace je načítána přes `lib/config.php`; podporuje explicitní `DB_DSN`
  i stávající kombinaci `DB_HOST`/`DB_PORT`/`DB_NAME`.
- Chybějící, neplatná nebo produkčně nebezpečná konfigurace selže obecnou
  odpovědí bez DB DSN, hesla nebo cesty k tajnému souboru.
- `config.example.php` a `docs/deploy/configuration.md` dokumentují povinné
  hodnoty bez vložení tajemství do repozitáře.
- `lib/session.php` centralizuje strict-mode PHP session, HttpOnly, SameSite,
  explicitní Secure policy, inicializační regeneraci ID a korektní destroy.
- `lib/http.php` poskytuje testovatelné method/CORS rozhodování a jednotný JSON
  error envelope; endpointy na něj budou přepojeny v následujících taskech.
- `lib/bootstrap.php` poskytuje request ID, bezpečné zpracování neočekávaných
  chyb a filtruje token/password/secret klíče ze strukturovaného security logu.
- Veřejná i administrátorská bootstrap cesta používá stejnou session konfiguraci.
- Apache dostal `Referrer-Policy` a `Permissions-Policy`; zastaralý
  `X-XSS-Protection` byl odstraněn.

## Bezpečnostní rozhodnutí

- Produkce vyžaduje HTTPS `APP_URL` a Secure session cookie.
- `APP_STORAGE_PATH` musí být explicitní absolutní cesta mimo web root; aplikace
  jej nedomýšlí z URL ani z aktuálního adresáře.
- Prázdný `STORE_ALLOWED_ORIGINS` znamená same-origin; helper nevrací `*`.
- Stripe klíče se pouze načítají do konfigurace. V tomto tasku se ještě
  nepoužívají; webhook a checkout budou fail-closed v následujících taskech.

## Nasazení a návrat

2. Ověřit PHP rozšíření `pdo_pgsql`, cestu storage mimo `public_html` a HTTPS.
3. Nahrát nové `lib/` soubory a `.htaccess` společně s konfigurací.
4. Otevřít veřejnou stránku, admin login a zkontrolovat server error log bez
   úniku tajemství.
5. Pokud konfigurace není připravena, nenasazovat tento release; návrat je
   obnovení předchozího kódu, protože Task 0.1 nemění databázi.
