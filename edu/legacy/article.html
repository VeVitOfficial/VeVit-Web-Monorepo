Úvod do JavaScriptu: Proměnné a datové typy

JN
Jan Novák · 8. dubna 2026 · 12 min čtení
JavaScript Začátečníci Základy

JavaScript je jedním z nejoblíbenějších programovacích jazyků na světě. V tomto článku se podíváme na základy — jak deklarovat proměnné a jaké datové typy v JavaScriptu existují.

Co je JavaScript?

JavaScript je dynamický programovací jazyk, který byl původně vytvořen pro interaktivitu webových stránek. Dnes se používá nejen na frontendu, ale i na backendu (Node.js), pro mobilní aplikace (React Native) nebo desktopové aplikace (Electron).

JavaScript není Java — ačkoliv názvy jsou podobné, jde o zcela odlišné jazyky s odlišnou historií a filosofií.

Proměnné

V JavaScriptu máme tři způsoby, jak deklarovat proměnné. Každý má své specifické použití a je důležité rozumět rozdílům mezi nimi.

let a const

Moderní JavaScript preferuje používání let a const před starším var. Rozdíl je v tom, že:

  • let — proměnná, jejíž hodnota se může změnit
  • const — konstanta, jejíž hodnota se nemůže změnit
// Proměnná, kterou můžeme měnit
let pocitadlo = 0;
pocitadlo = pocitadlo + 1; // OK

// Konstanta - hodnota se nemění
const PI = 3.14159;
PI = 3.14; // Chyba! Nelze přiřadit novou hodnotu

Datové typy

JavaScript má sedm primitivních datových typů a jeden komplexní typ (Object). Podívejme se na primitivní typy.

Primitivní typy

  1. string — textové řetězce
  2. number — čísla (celá i desetinná)
  3. boolean — logické hodnoty true/false
  4. undefined — nedefinovaná hodnota
  5. null — prázdná hodnota
  6. symbol — unikátní identifikátor
  7. bigint — velká celá čísla
// Příklady primitivních typů
const jmeno = "Jan";        // string
const vek = 25;             // number
const aktivni = true;       // boolean
const neznano = undefined;   // undefined
const prazdne = null;        // null

Operátory

Pro práci s proměnnými a hodnotami používáme operátory. Zde jsou nejčastěji používané:

  • Aritmetické: +, -, *, /, %
  • Porovnávací: ===, !==, >, <
  • Logické: &&, ||, !
  • Přiřazovací: =, +=, -=
